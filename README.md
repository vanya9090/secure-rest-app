# secure-rest-app

Учебный REST API для первой лабораторной работы по информационной безопасности. Приложение хранит посты в SQLite и предоставляет три эндпоинта: вход, получение списка постов и создание поста. Стек: Python 3.10, FastAPI, Pydantic, SQLAlchemy, SQLite.

## API

- `/auth/login POST` - Создать пользователя при первом входе либо войти, вернуть JWT
- `/api/data POST` - Создать пост от имени вошедшего пользователя
- `/api/data GET` - Получить все посты


## Реализованные меры защиты

| Требование | Реализация |
| --- | --- |
| Защита от SQL-инъекций | Чтение выполняется через выражения SQLAlchemy `select(...)`, запись - через ORM-объекты. Пользовательский текст не подставляется в SQL конкатенацией строк |
| Защита от XSS | Pydantic-сериализатор экранирует поля при возврате JSON |
| Защита паролей | В таблице пользователей хранится хэш Argon2, созданный `pwdlib`, а не открытый пароль |
| Аутентификация | При входе выдаётся подписанный JWT с идентификатором пользователя, временем выдачи и сроком действия |
| Авторизация | `get_current_user` проверяет Bearer-токен и наличие пользователя в БД перед обоими методами `/api/data` |


## CI и проверки безопасности

Workflow [`.github/workflows/ci.yml`](.github/workflows/ci.yml) запускается при `push` и `pull_request` и содержит две проверки:

- SAST: Bandit анализирует исходный код в `app/` и загружает JSON-отчёт `bandit-report`
- SCA: Snyk проверяет зависимости, экспортированные из `uv.lock`, и загружает JSON-отчёт `snyk-report`
